# Privacy contract review: requirement and evidence map

This reconciles review addendum PC01–PC12 with the current behavior contract. It is not a public privacy policy, legal certification or live acceptance report. Existing owning clauses remain authoritative; the map does not introduce duplicate consent, storage or summarization subsystems. Dated execution results belong in the [verification report](../VERIFICATION_REPORT.md).

## Scope reconciliation

The addendum describes CHZZK's earlier manual-delivery implementation. The operator subsequently explicitly requested automatic guidance for YouTube and CHZZK, implemented in `841e06c`. That explicit product decision is retained for this review: CHZZK uses its official server sender with acknowledgement of every notice part and no manual-completion shortcut. The earlier manual CHZZK acceptance examples are superseded by these sender checks; manual delivery is not retroactively described as an unfulfilled requirement. SOOP remains browser-based and YouTube server-based. See the [platform matrix](behavior-requirements.md#platform-execution-and-notice-delivery).

No live screen/audio capture, mask confirmation, third-party timing service, guardian verification, AI age inference, persistent ordinary chat, remote/free-text summarization or Codex CLI/IDE/app-server wrapper is added. Operator OpenAI authentication is not viewer consent. Actual display nicknames remain; opaque session speaker keys in model metadata are pseudonymous keys, not display aliases or proof that message bodies are anonymous.
