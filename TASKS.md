Standalone legacy persistent Store, capture/STT/Jev and manual persona authoring tests remain for library regression coverage. They are not exposed as alternate live privacy paths. The recent participation/withdrawal and fixed-notice implementation checks used synthetic fixtures, not real provider deletion, platform delivery or VOD operations. Earlier live experiments are scoped in the dated verification report. See [privacy acceptance table](docs/privacy-implementation.md#acceptance-and-operational-checks) for T01–T26 scope.

The [PC01–PC12 review](docs/privacy-review-evidence.md) maps existing requirements to evidence instead of adding duplicate subsystems. The verified credential-retention race (late refresh restoring forgotten SOOP/CHZZK/ChatGPT secrets) is fixed and regression-tested. Actual final public-policy equivalence, account/workspace data settings and post-session contact delivery remain unverified operational checks, alongside the platform/provider acceptance above. CHZZK automation follows the explicit operator request recorded in the current contract, superseding the addendum's older manual-path description.
